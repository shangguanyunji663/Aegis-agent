# 2026-08-19

## 评测体系重写（真实数据 + 去满分门限）

按场景#15"日常开发"需求，将工程验证脚本与评测体系重写为基于真实代表性数据集、且不再人为凑 100%。

### 新增真实数据集（eval/fixtures/）
- `representative_corpus.json`：150 条唯一真实代表性消息（含隐式高危、第三人称干扰、hard 无关键词样本），逐条标注 expected_intent/expected_risk。
- `rag_queries.json`：50 条自然语言检索问句（基于 knowledge/ 12 篇真实文档，非关键词堆砌），替换原 aegis-rag-eval.json（66 条关键词堆砌）。
- `multi_turn_corpus.json`：8 组多轮场景（含升级到中/高风险、第三人称转自身）。

### 代码改动
- `app/evaluation/datasets.py`：加载器 + 可复现随机抽样，移除循环生成伪样本。
- `app/evaluation/runner.py`：路由/风险/规模化/多轮/RAG 全改用真实语料，输出意图/风险准确率、高风险召回、误报率、HitRate/Recall@4/Precision@4/MRR/NDCG@4，附样本规模/数据来源/验证日期/95% Wilson CI；移除 `all_passed==100%` 门限。
- `app/rag_eval/runner.py`：修复独立运行 __main__ 误触 MySQL/pymysql 的 bug（改为一次性 SQLite 评测库）。
- `app/harness/runner.py`：移除 RAG≥0.9 / 规模化=100% / 风险=100% 硬性阈值门限，仅保留工程行为级断言。
- `app/assessment.py`：HIGH_TERMS 增补隐式高危表达（一了百了/解脱/结束这一切/结束自己的生命/活下去的理由(力气)/不再醒来/永远睡过去/活着多余/死了算了），真实提升高风险召回且不引入新误报。
- `app/agents/classic.py`：LeadAgent.route 词表扩充为通用中文求助表达（路由 0.50→0.61）。
- `app/config.py`：rag_eval_dataset 指向 rag_queries.json。
- `tests/test_runtime_ab.py`：A/B 消息集扩至 10 条代表性样本，断言改为动态长度。

### 真实验证结果（2026-08-19，MockLLM 确定性环境）
- 路由准确率 0.61、风险准确率 0.77、高风险召回 0.57、误报率 0.033
- RAG：HitRate 0.94 / MRR 0.84 / NDCG@4 0.86 / Precision@4 0.33
- 多轮 0.875；三运行时 A/B 判定完全一致（意图 0.8/风险 0.9）
- 测试：排除依赖 MySQL 的 test_api 后 57 passed、1 failed（test_langgraph_checkpoint 跨实例持久化为既有环境问题，与本次无关）

### 关键结论（已写入 README）
非 100% 反映规则引擎真实能力边界：隐喻式自杀意念需 LLM 风险通道；无关键词咨询/研究诉求需 LLM 意图通道；第三人称提及高危词需说话人消歧。生产开启 RISK_LLM_CHANNEL_ENABLED 后召回更高。
